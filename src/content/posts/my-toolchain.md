> 占位草稿：把下面的条目换成你真实在用的工具。

写这个博客，我的工具链大概是：

1. **编辑器**：VS Code + Astro 插件
2. **写作**：纯 Markdown，新文章用 `pnpm new-post <文件名>` 一键生成骨架
3. **版本管理**：Git + GitHub（仓库 `kiuyor/ink_blog`）
4. **部署**：推到 main 后自动构建出静态文件

::tip{title="为什么喜欢纯文本"}
Markdown 是"未来的proof"——十年后你还能打开它，换个引擎（Hugo / Hexo / 任意 SSG）照样渲染，数据永远归自己。
::
