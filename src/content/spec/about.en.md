# About ink_blog

This is **ink**'s personal blog *ink_blog*, subtitled "磨叽的墨迹" (the ink stains of a dilly-dallying writer).

::github{repo="kiuyor/ink_blog"}

## Why it exists

I didn't start this blog to become "yet another platform account" — I wanted a corner of the web that is **wholly my own**.

Compared to platforms like WeChat Official Accounts, Juejin, or CSDN, here are the things they can't offer:

- **Data 100% yours**: posts are just Markdown files — permanent URLs, no ads, no platform moderation, no ranking manipulation.
- **No algorithm, no subscription lock-in**: whether you see my writing doesn't depend on what some recommender system feels like today.
- **Leave anytime**: pure static HTML + Markdown sources — migrate to Hugo / Hexo / any SSG you like, zero vendor lock-in.

In other words, this is a **tech business card** that's truly yours — putting `blog.suchitems.top` on a résumé beats pasting a WeChat link by a mile.

## What it can write

It's a fully static site built with **Astro + Svelte** — no backend, no database — yet the writing experience is "tailor-made for tech bloggers":

- Math (KaTeX), code highlighting (line numbers / folding / language badges / custom copy buttons)
- GitHub cards, admonitions (note/tip/warning), reading time, galleries
- Bilingual (Chinese / English)

## What I'll write

Notes from technical tinkering, fragments of reading and papers, and a few half-baked but worth-keeping ideas.

> If something here helped you, that's its greatest meaning. Feel free to comment under any post, or find me on GitHub.
