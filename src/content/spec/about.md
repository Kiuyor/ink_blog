# 关于 ink_blog

这里是 **墨水** 的个人博客 *ink_blog*，副标题叫「磨叽的墨迹」。

::github{repo="kiuyor/ink_blog"}

## 它为什么存在

我开这个博客，不是要做一个"又一个内容平台账号"，而是给自己留一块**完全属于自己**的地方。

对比公众号、掘金、CSDN 这类平台，这里有几个它们给不了的东西：

- **数据 100% 归你**：文章就是一堆 Markdown 文件，URL 永久、无广告、无平台审核、无排名操纵。
- **没有算法，也没有订阅绑架**：你能不能看到我的文章，不取决于某个推荐系统今天心情如何。
- **随时能走**：纯静态 HTML + Markdown 源文件，想迁到 Hugo / Hexo / 任意 SSG 都行，没有任何供应商锁定。

换句话说，这是一张真正属于你的**技术名片**——简历里写 `blog.suchitems.top`，比贴一个公众号链接有说服力得多。

## 这里能写什么

它是基于 **Astro + Svelte** 的纯静态站点，零后端、零数据库，但写作体验是"技术博主特供"的：

- 数学公式（KaTeX）、代码高亮（行号 / 折叠 / 语言徽章 / 自定义复制按钮）
- GitHub 卡片、提示框（note/tip/warning）、阅读时长、画廊
- 中英双语（已上线，右上角可切换 中 / EN）

## 我会写什么

技术折腾笔记、读书与论文的碎片思考，以及一些不成熟但想留痕的想法。

> 如果某篇帮到了你，那便是它最大的意义。欢迎在文章下留言，或去 GitHub 找我。
